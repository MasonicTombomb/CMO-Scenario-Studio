## OpenStreetMap data (UK air base templates)

`src/cmo_studio/data/templates_uk.json` contains UK air base layouts (runway positions, headings and lengths,
hardened aircraft shelters, hangars, aprons, control towers, radars, fuel and munitions storage) derived from
OpenStreetMap data.

`templates_uk.json` is a derivative database and is made available under the ODbL 1.0. This applies only to that
data file; the CMO Scenario Studio source code remains under the MIT License (see `LICENSE`). The other UK sites
in the same file (naval bases, radar heads, headquarters, garrisons) are schematic layouts at the real positions
built from public sources.
