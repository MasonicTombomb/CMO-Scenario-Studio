# Settings and updates

## Settings

Open **File > Settings...**. The window is described in Chapter 2, *The first start*. In short:

| Setting | Use |
| --- | --- |
| CMO folder | Where CMO is installed. **Browse...** to choose it, **Detect** to search Steam again. |
| Autosave | Minutes between safety copies of your project, or *off*. |
| Custom map tiles | The web address of your own map server, in `https://.../{z}/{x}/{y}.png` form. Then choose *Custom* in the map's **Map** box. |
| Updates | Whether to check GitHub for a new version at start-up. |

## Updates

See Chapter 2, *Updating*. To check now, choose **Help > Check for updates...**. **Help > Release notes (GitHub)**
opens the list of every version and what changed.

## Your own libraries

The template, area and callsign libraries can each be edited (**Tools > Template library...**, **Tools > Area
library...**, **Tools > Callsign library...**). Your edited library is saved in your user folder, never in Program
Files, so it survives updates. When an update adds new built-in templates or areas, they are added to your library
automatically; anything you deleted stays deleted. Each library window has **Import...**, **Export...** and **Reset
to defaults** to share libraries or start again.
