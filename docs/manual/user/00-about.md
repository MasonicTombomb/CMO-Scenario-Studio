# About this manual {.unnumbered}

This manual teaches you to use **CMO Scenario Studio** from scratch. You do not need to know anything about
programming, Lua scripting or how *Command: Modern Operations* (CMO) stores its scenarios. If you can use a web
browser and a word processor, you can build a scenario with this manual.

## How the manual is organised

| If you want to... | Read |
| --- | --- |
| Install the studio and get it talking to CMO | Chapter 2, *Installing the studio* |
| Learn your way around the screen | Chapter 3, *A tour of the window* |
| Build and play a complete scenario today | Chapter 4, *Your first scenario, step by step* |
| See what a finished scenario looks like | Chapter 5, *Exploring the example scenario* |
| Look up one tab, panel or dialog | Chapters 6 to 21, one per part of the studio |
| Get your scenario into CMO and play it | Chapter 22, *Exporting and building in CMO* |
| Fix a problem | Chapter 24, *Troubleshooting*, and Chapter 25, *Questions and answers* |
| Look up a military or CMO term | Appendix B, *Glossary* |

If you are completely new, read chapters 1 to 4 in order and do the tutorial in Chapter 4 with the studio open
next to you. Everything after that is reference you can dip into when you need it.

The companion **Reference Manual** covers the file formats, the Lua the studio generates, the runtime functions
your own scripts can call, and how to edit the libraries by hand. You never need it to build scenarios; it is
there for advanced users and modders.

## Conventions used in this manual

| You see | It means |
| --- | --- |
| **Save** | A button, tab, menu item, checkbox or other control, written exactly as it appears on screen. |
| **File > Settings...** | A menu path: open the **File** menu, then choose **Settings...**. |
| [[Ctrl+S]] | Keys to press together: hold **Ctrl** and press **S**. |
| `Lua\Baltic Sentinel\` | Something you type, a file name or a folder. |
| *(default)* | A value shown in a list or box, in italics. |
| Numbered orange circles on a picture | Call-outs. The text under the picture explains each number. |

Boxes like these appear throughout:

!!! tip "Tip"
    A shortcut or a good habit that saves you time.

!!! note "Note"
    Background that helps you understand what is going on.

!!! warning "Watch out"
    A common mistake, or something that can cost you work if you get it wrong.

!!! example "Example"
    A worked example you can copy.

## What the pictures show

The screenshots use the example scenario *Baltic Sentinel* that comes with the studio (see Chapter 5), so you can
open the same project and compare. Your screen may look slightly different: panels can be resized and moved, and
the map may show different areas or tiles.

## Version

This manual describes CMO Scenario Studio version 1.8.0. The studio checks for updates itself (Chapter 23); the
manual for the version you have installed is always in the **Help** menu.
