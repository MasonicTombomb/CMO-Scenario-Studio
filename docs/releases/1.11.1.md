## CMO Scenario Studio 1.11.1 — Intercept Fixes

Fixes for the intercept missions added in 1.11.0. **Re-export and rebuild** scenarios that use them.

### Fixed

- **"An item with the same key has already been added"** exceptions in CMO. The intercept manager could give a mission
  the same target twice. It now adds each aircraft once, whatever CMO answers and even when a lost track comes back as a
  new contact, and it switches the mission on only when it is off instead of every half minute.
- **Every base's aircraft on one mission.** In the mission editor the air base box kept the previous mission's base and
  its button only added, so QRA North and QRA South could end up sharing Lossiemouth and Coningsby. **Aircraft on call**
  is now a list of bases with tick boxes: tick a base to put its aircraft on call, untick it to take them off. A base
  whose aircraft are on another mission says so, and the studio asks before moving them.
- **An aircraft can be on call for one intercept only**: the Issues panel reports it, the export lists it once, and the
  manager never takes an aircraft that another intercept is using.
- **Messages** no longer show `<P>` tags.

### Improved

- **Go home at**: aircraft return to base when they reach this much fuel (30 % unless you change it), and another takes
  their place. In 1.11.0 an aircraft could chase until it ran out.
- `StudioInterceptReport()` in CMO's Lua console prints what each intercept holds, for bug reports.
