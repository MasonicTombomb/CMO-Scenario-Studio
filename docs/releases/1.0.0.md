## CMO Scenario Studio 1.0.0 — Version 1

The first release of a desktop scenario creation suite for *Command: Modern Operations*.

### Download

**`CMO-Scenario-Studio-1.0.0-win64.zip`** — unzip anywhere and run `CMO-Scenario-Studio.exe`. No Python needed.
Requires Windows 10/11 (64-bit) and a CMO installation (the studio reads its `DB\*.db3` databases and uses its
`lua54.dll` for dry-runs). Check the download against the `.sha256` file if you like.

On first start the studio looks for CMO in your Steam libraries; otherwise choose the folder in **File > Settings**.
Open `examples\Baltic Sentinel.cmoproj` for a complete scenario, and see `docs\USER_GUIDE.md`.

### What it does

- Build scenarios on a real map with values from your DB3000/CWDB database: units, airbases with squadrons and
  loadouts, reinforcements, areas, reference points, missions, events, special actions, Lua scripts and briefings.
- Export the folder layout used by the official Lua-driven scenarios: a one-shot `Build_Scenario.lua` you run in the
  editor's Lua console, the runtime scripts events need, and `[LOADDOC]` description and briefing pages.
- "Play as X" build variants with computer-controlled opponents.
- Validation of every DBID and loadout against the database, and a dry-run of the whole build in CMO's own Lua
  before you open the game.
- Safe exports into the CMO folder (only studio-written files are replaced; backups are zipped first).
- Import the order of battle from an *If Russia Wins*-style `Build_Scenario.lua`.

### Notes

- Windows SmartScreen may warn because the exe is not code-signed: choose *More info > Run anyway*.
- Map tiles need an internet connection (Esri, OpenStreetMap, OpenTopoMap); *None (offline grid)* works offline.
- Command line: `CMO-Scenario-Studio.exe project.cmoproj --dry-run` or `--export <folder>`.
- Not affiliated with Matrix Games, Slitherine or WarfareSims; no game data is included.
