## CMO Scenario Studio 1.1.0 — Loadout Viewer

### New: Loadout Viewer

Open it with **Tools > Loadout viewer** (Ctrl+L), the **Loadout viewer** button in the Database dock, or
**View loadouts...** on any aircraft in the unit inspector.

- Every loadout of an aircraft, filterable by role group (air-to-air, strike/SEAD/CAS, support, ASW, recon,
  tanker) and by text, including the weapons carried (`JASSM`, `AIM-120`...).
- Loadout details: role, day/night and weather, combat radius, time on station, ready and sustained ready time,
  quick turnaround, default mission profile, Winchester/Shotgun rule, drag modifier and total weapons payload.
- Each store with quantity, maximum, type, air/surface/land/subsurface range, weight, internal/optional.
- Per weapon: image, ranges, PoK, CEP, flight limits, targets, warheads, seekers, capabilities and description.
- Linked browsing: every aircraft that carries the loadout, every loadout that carries the weapon, and the units
  in your project using it — double-click to follow, Back/Forward to retrace.
- **Use for selected aircraft** applies the loadout to the selected squadron in one click.

### Download

**`CMO-Scenario-Studio-1.1.0-win64.zip`** — unzip anywhere and run `CMO-Scenario-Studio.exe`; no Python needed.
Requires Windows 10/11 (64-bit) and a Command: Modern Operations installation. Projects from 1.0.0 open unchanged.

Windows SmartScreen may warn because the exe is not code-signed: choose *More info > Run anyway*.
