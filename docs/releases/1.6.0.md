## CMO Scenario Studio 1.6.0 — Installer and Automatic Updates

### New: Windows installer

**`CMO-Scenario-Studio-1.6.0-setup.exe`** installs the studio into `C:\Program Files\CMO Scenario Studio` for all
users, like any other application:

- Start-menu shortcuts (studio, user guide, example projects, uninstall) and an optional desktop icon.
- Optionally opens `.cmoproj` project files with the studio.
- A normal uninstaller (*Settings > Apps*). Upgrades replace the old program files cleanly.

The program and its built-in libraries live in Program Files. Your own libraries, settings, export backups, the map
tile cache and your projects stay in your user profile, so updating or uninstalling never touches them. Saving an
example opened from Program Files asks where to save your copy.

### New: updates from GitHub

The installed studio checks GitHub for a new release a few seconds after it starts (switch this off in
*File > Settings*); **Help > Check for updates** checks at any time. *Download and install* shows the release notes,
downloads the setup over HTTPS from GitHub, verifies it against the release's SHA-256 checksum, asks you to save
your work, then closes, updates and restarts. *Skip this version* stops the reminder for that version. Portable
copies open the release page instead.

**Coming from 1.5.2 or earlier?** Run the 1.6.0 setup once; from then on the studio updates itself. Your
settings and libraries carry over.

### Also

- Code-signing support in the release build (exe, setup and uninstaller) for when a certificate is configured;
  once releases are signed, the updater only installs setups from the same publisher.
- Save As defaults to Documents.
- `docs/RELEASING.md` explains where files go, how updates work and how releases are built and signed.

### Download

- **`CMO-Scenario-Studio-1.6.0-setup.exe`** - installer (recommended).
- **`CMO-Scenario-Studio-1.6.0-win64.zip`** - portable: unzip anywhere and run `CMO-Scenario-Studio.exe`.

Requires Windows 10/11 (64-bit) and a Command: Modern Operations installation. No Python needed. Projects from
earlier versions open unchanged.

This release is not code-signed yet, so Windows SmartScreen may warn about an unknown publisher: choose
*More info > Run anyway*.
