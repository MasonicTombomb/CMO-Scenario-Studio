## CMO Scenario Studio 1.9.1 — Forecast Fix, Submarine Depth

### Fixed

- **The weather forecast now reaches CMO.** In 1.9.0 the forecast table was left out of `Build_Scenario.lua`, so
  no weather change was ever built. **Re-export and rebuild** any scenario that uses **Weather Forecast...**. The
  exporter now writes every build table automatically, so this cannot recur.

### Improved

- **Submarine depth on each leg.** In the course window a submarine has a **Depth** setting per leg (0 surfaces),
  a Depth column in the leg table and a depth profile under the map. CMO is given the new depth as each leg starts.
- **Ground units stop while they wait** at a waypoint, instead of driving a small loop. Aircraft, ships and
  submarines still circle.

### Documentation

- User Manual Chapter 14: the depth setting and how each kind of unit waits.
- Reference Manual: the weather forecast in the build order, the `D.FORECAST` table, the project's `forecast` list,
  and waypoint depth.
- Both PDF manuals rebuilt.
