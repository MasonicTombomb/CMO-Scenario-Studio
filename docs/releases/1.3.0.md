## CMO Scenario Studio 1.3.0 — Timeline, Search and Bulk Editing

### New: Event timeline

A **Timeline** tab puts every event and mission on the scenario clock, in Zulu and H+ time.

- **Diamonds** fire once (date/time, minutes after start, scenario loaded or ended); **bars** are random-time
  windows and mission active periods; **ticked bars** repeat on a timer; **dotted lines** fire on a condition.
- Missions switched on or off by a timed event show where that happens.
- **Timing problems** are listed: events before the start or after the end, random windows outside the scenario,
  missions that end before they start, events without triggers, and one-shot events in the same minute.
- Hover for details, Ctrl+wheel to zoom, double-click to edit the event or mission.

### New: Search everything (Ctrl+K)

Find any unit (by name, class, DBID, group or base), side, mission, event, area, reference point, formation, special
action, variant or script, every line of every script, and studio commands such as "Dry-run build". Enter opens the
result in the tab that edits it; script lines open at that line.

### New: Edit many units at once

Select units on the Units tab and press **Edit selected...** (or right-click, or Ctrl+Shift+E). Tick only the fields
to change, as one undo step:

- **Rename** with `{name}`, `{n}`, `{nn}`, `{class}`, `{side}` and `{type}` (e.g. `Escort {nn}`).
- **Side**, which also drops the units' old-side missions, strike targets, formation places and bases.
- Group, count, proficiency, radar/sonar, hold position, auto-detectable, reinforcement, heading, speed, altitude,
  depth, base, loadout (one aircraft type) and extra unit fields.

### Also

- Double-clicking an issue in the Issues panel opens it in the tab that edits it.

### Download

**`CMO-Scenario-Studio-1.3.0-win64.zip`**: unzip anywhere and run `CMO-Scenario-Studio.exe`; no Python needed.
Requires Windows 10/11 (64-bit) and a Command: Modern Operations installation. Projects from earlier versions open
unchanged.

Windows SmartScreen may warn because the exe is not code-signed: choose *More info > Run anyway*.
