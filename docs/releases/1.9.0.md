## CMO Scenario Studio 1.9.0 — Dynamic Weather Forecast

### New

- **Weather forecast.** Schedule weather changes after the scenario starts: click **Weather
  Forecast...** on the Scenario tab to open a table of timed changes. Each row gives an offset
  in minutes and new values for temperature (°C), rainfall (0–50), cloud (0–1) and sea state
  (0–9). The build turns each entry into a one-shot CMO event that fires at the right time and
  calls `ScenEdit_SetWeather`. Initial T+0 conditions are still set on the Scenario tab as
  before.

### Download

- **`CMO-Scenario-Studio-1.9.0-setup.exe`** — installer. If you have 1.6.0 or later installed, the studio offers
  this update itself.
- **`CMO-Scenario-Studio-1.9.0-win64.zip`** — portable.
- **`CMO-Scenario-Studio-User-Manual.pdf`**, **`CMO-Scenario-Studio-Reference-Manual.pdf`** — the manuals.

Requires Windows 10/11 (64-bit) and a Command: Modern Operations installation. This release is not code-signed yet,
so Windows SmartScreen may warn about an unknown publisher: choose *More info > Run anyway*.
