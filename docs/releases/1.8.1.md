## CMO Scenario Studio 1.8.1 — Course Fixes and Documentation

### Fixed

- **Targets setting on a course leg.** *Leave the course to attack* and *Stay on the course* now send CMO `yes` /
  `no`, the same values as the Sides tab's *Ignore plotted course* doctrine. In 1.8.0 they sent `true` / `false`.
  Re-export and rebuild scenarios that use this setting.

### Checked

- Courses work for **ships, submarines and ground units** as well as aircraft. New tests play each type through a
  course in the dry-run: departure time, leg speed, radar or sonar, weapons, a wait at a waypoint and a signal.

### Documentation

- The User Manual (Chapter 14) has a table of which leg settings each kind of unit uses: altitude is for aircraft,
  sonar is not offered for ground units, and only aircraft take off from a base.
- New glossary entries (course, leg, waypoint, signal), a FAQ entry on making computer units follow a set route, and
  the course keys in the keyboard table.
- The README feature list and the architecture notes cover courses.
