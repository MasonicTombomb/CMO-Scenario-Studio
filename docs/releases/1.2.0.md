## CMO Scenario Studio 1.2.0 — Formations and Loadout Viewer

1.1.0 was tagged but its release build never finished, so this release includes everything from it.

### New: Formations

A **Formations** tab and **Create units in formation...** (Ctrl+Shift+F).

- **40 layouts** with their own settings:
  - *Naval:* line ahead, line abreast, echelon left/right, wedge, inverted wedge, diamond, box, convoy, circular
    screen, carrier group (inner + outer screen), ASW bent-line screen, picket line, amphibious assault lanes,
    mine-sweeping echelon.
  - *Air:* finger four, vic, trail, ladder (stepped altitude), combat spread, wall, box, wedge, echelon, bomber
    stream, tanker cell.
  - *Ground:* road column, staggered column, herringbone, line, wedge, vee, echelon, box, diamond, coil/laager,
    SAM battery dispersal, random dispersal, defensive perimeter.
  - *Custom stations:* type each member's bearing and distance.
- **Controls:** spacing in nm, km or m; orientation; altitude step per aircraft; mirror; jitter with a seed;
  member order and lead.
- **Creator:** build a group straight from database entries (e.g. one carrier and six destroyers) in any layout,
  with a live preview. Or turn existing units into a formation from the Units tab or the map's right-click menu.
- **On the map:** dashed lines join each lead to its members; with *keep on station* ticked, dragging the lead or any
  member moves the whole formation.
- **In CMO:** each formation is built as a group with formation stations (Rotating or Fixed, optional sprint and
  drift), using the same Lua calls as the official scenarios. Units are placed on station first, so if grouping is
  refused they keep their layout and the build report says so.

### New: Loadout Viewer

Tools > Loadout viewer (Ctrl+L), or from the Database panel and the aircraft inspector.

- Every loadout of an aircraft, filterable by role group and by the weapons it carries.
- Loadout details: role, conditions, combat radius, time on station, ready and quick-turnaround times, mission
  profile, Winchester/Shotgun rule, stores with quantities, ranges and weights, and total payload.
- Weapon details: ranges, PoK, CEP, flight limits, targets, warheads, seekers, capabilities and description.
- Linked browsing with Back/Forward: which aircraft carry a loadout, which loadouts carry a weapon, and which of your
  units use it. **Use for selected aircraft** applies a loadout in one click.

### Fixes

- The release build no longer hangs (a first-run prompt could open during tests on a machine without CMO).

### Download

**`CMO-Scenario-Studio-1.2.0-win64.zip`**: unzip anywhere and run `CMO-Scenario-Studio.exe`; no Python needed.
Requires Windows 10/11 (64-bit) and a Command: Modern Operations installation. Projects from 1.0.0 open unchanged.

Windows SmartScreen may warn because the exe is not code-signed: choose *More info > Run anyway*.
