## CMO Scenario Studio 1.6.1 — PDF Manuals

### New: User Manual and Reference Manual (PDF)

**CMO Scenario Studio User Manual** (85 pages) - written for complete beginners, no programming needed:

- Installing the studio and pointing it at CMO, and a numbered tour of the window.
- **Your first scenario, step by step**: a 16-step tutorial that builds *Operation First Light* from nothing - RAF
  Lossiemouth with Typhoons, a Type 23 frigate hunting a Russian Yasen-M in the Faroes-Shetland gap, patrol areas,
  missions, events and briefings - then builds it in CMO and plays it.
- One chapter per tab and dialog, with annotated screenshots: scenario, sides, map, database, units and squadrons,
  formations, templates and real UK sites, areas, missions, events, special actions, scripts, briefings, timeline,
  search, checking, exporting and building in CMO, settings and updates.
- Troubleshooting by symptom, questions and answers, keyboard shortcuts, a glossary of military and CMO terms and a
  menu reference.

**CMO Scenario Studio Reference Manual** (53 pages) - for advanced users and modders: files and command line, project
and export formats, the exported Lua and runtime API, events in depth, formation layouts, the template, area and
callsign libraries with full catalogues, database access, importing and releasing.

Open them from **Help > User manual (PDF)** (F1) and **Help > Reference manual (PDF)**, from the Start menu, or
download them from this release.
