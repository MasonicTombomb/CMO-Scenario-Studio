## CMO Scenario Studio 1.4.0 — Callsigns

### New: Callsign library

A standalone, editable JSON library of callsigns by country, squadron and role.

- **38 air arms**: the major NATO members (US, UK, France, Germany, Italy, Spain, Netherlands, Norway, Denmark,
  Poland, Turkey, Canada, Belgium, Greece, Sweden, Finland, Romania, Czech Republic, Hungary, Portugal, the Baltic
  states) and NATO's own units; Russia, China, India, Iran, Israel, Japan, South Korea, North Korea, Australia,
  Pakistan, Saudi Arabia, Ukraine, Egypt, Brazil and Taiwan; and a Generic fallback.
- **About 365 squadrons**, each with service, base, aircraft, the roles it flies and its callsign words (1,100+ in
  all).
- **18 roles**: fighter, strike, close air support, SEAD, maritime strike, bomber, AEW, EW, reconnaissance, maritime
  patrol, tanker, transport, naval / attack / utility helicopters, search and rescue, drones and trainers, with
  fallbacks when a country has no squadron for a role.
- **Flights**: each word gives numbered flights (`TARTAN 11-14`, `TARTAN 21-24`...); name format and flight size are
  set per country (`SOKOL-11` for Russia).

Squadron details are a realistic starting point; callsign words are illustrative, in each air arm's style.

### New: Assign callsigns

Units tab *Callsigns...*, right-click, or Ctrl+Shift+C.

- Detects each aircraft's **country** from its database operator and its **role** from type, category and current
  loadout (an F-16 with HARMs is SEAD, a Ka-27 a naval helicopter). Override country, role or squadron per row with a
  live preview.
- Optionally **splits counted units** into single aircraft with their own callsigns, keeping base, missions and
  formation places, and puts the squadron name in each unit's group tag.
- Separate units come from separate squadrons, each unit starts a new flight, and names already used in the
  scenario are never reused. One undo reverts everything.

### New: Callsign library editor

Tools > Callsign library: add, rename and remove countries, squadrons, roles and words, and set each country's name
format and flight size. *Save* writes your own `callsigns.json` (used instead of the default), which you can also
edit by hand, *Export* / *Import* to share, or *Reset to defaults*. The format is documented in `docs/CALLSIGNS.md`.

### Download

**`CMO-Scenario-Studio-1.4.0-win64.zip`**: unzip anywhere and run `CMO-Scenario-Studio.exe`; no Python needed.
Requires Windows 10/11 (64-bit) and a Command: Modern Operations installation. Projects from earlier versions open
unchanged.

Windows SmartScreen may warn because the exe is not code-signed: choose *More info > Run anyway*.
