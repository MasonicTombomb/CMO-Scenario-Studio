## CMO Scenario Studio 1.10.0 — Planning and Briefing

A big release for building scenarios faster and making them feel real: plan timed operations, check them against
range and the clock, script events from recipes, start from a wizard, and hand each side a NATO-style briefing pack.

### Plan operations

- **Time on target.** Give a course waypoint an *Arrive at* time. The course window, Timeline and Issues panel show
  whether the unit is on time, early or late, and the speed a late leg needs. **Time it** sets the departure (and
  adds waits) so it arrives on time.
- **Range check.** For aircraft with a loadout, the route (waits included) is compared with an estimated range from
  CMO's database; the profile marks where the fuel should run out and the Issues panel warns.
- **Map clock.** Drag the *Clock* under the map to see where every unit with a course should be at any moment, with
  the weather and the timed events so far.
- **Reusable courses.** *Library ▾* in the course window saves a course with all its leg settings, uses a saved one,
  or copies the course to other units.
- **Weather on the Timeline.** Forecast changes appear as a row of diamonds; the Issues panel checks them.

### Build faster

- **New Scenario wizard** (*File > New scenario from wizard...*, Ctrl+Shift+N): sides, real UK air bases (or a
  generic base) with fighters on combat air patrol, patrol areas, an enemy bomber probe and standard events.
- **Place several templates at once**: tick RAF Fairford, RAF Benson and RAF Lossiemouth (or a whole category) and
  place them all, each at its real site.
- **Select several units on the map**: Ctrl-click, Shift-drag a box or Ctrl+A; drag one to move them all;
  right-click to edit them, give them one course, add them to a mission, make a formation or delete them.
- **Event recipes**: ten common events (points for kills, victory, reinforcements, missions at a time or on a
  signal, messages...) from a short form.

### Brief the players

- **Briefing packs**: *Briefing pack (PDF)...* on the Briefings tab writes a NATO-style operation order for a side -
  the five paragraphs, an intelligence summary (enemy order of battle, air defence threat, enemy courses of action),
  the air tasking schedule with each flight's leg orders and times on target, and a weather annex - with EXERCISE
  banners on every page. Generated from the scenario; your own text replaces any part. Save it as a PDF, one per
  side, or use it as the in-game briefing.
- **Flight schedule**: *Insert ▾ > Flight schedule* adds a table of every routed unit to a briefing.

### Under the hood

- `tools/release_check.py` checks a release before it is tagged (version everywhere, changelog, notes, manuals
  rebuilt, build tables, tests, git state); the release workflow runs it before publishing.
- The User and Reference Manuals cover all of the above, with new screenshots.

Projects from earlier versions open unchanged.
